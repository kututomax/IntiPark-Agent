# IntiPark Agent

Distribution of verified, generic Windows binaries for IntiPark.

This repository does **not** contain the IntiPark SaaS application source, customer settings, camera addresses, credentials, tokens, or collected readings.

Download the runtime asset from the versioned release required by your IntiPark installation. Your parking administrator supplies the private configuration separately through the authenticated panel.

Published assets include the bundled third-party license notices. Runtime integrity is checked against the SHA-256 descriptor distributed with the private application.
